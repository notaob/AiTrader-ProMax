项目经验
AiTrader - AI 智能交易辅助平台 | 独立全栈开发 | 项目链接: https://github.com/notaob/AiTrader-Pro.git
项目简介: 独立完成前端、业务后端、AI Agent 三服务开发，面向投资场景实现实时行情展示、AI 策略分析、多轮会话上下文管理与知识增强问答，构建具备持续扩展能力的 AI 交易辅助平台。
技术栈: React 19 + TypeScript + Vite + TanStack Query + Spring Boot 3.5 + MyBatis Plus + MySQL + Redis + RabbitMQ + FastAPI + LangGraph + LangChain + DashScope
LangGraph Agent 工作流: 基于 LangGraph 构建 ReAct Agent，封装当前价格、市场状态、技术分析、交易建议、知识库查询与写入等工具，支持普通问答与策略报告双模式输出。
会话与消息系统: 设计 conversationId 驱动的多轮会话链路，完成会话创建、历史消息查询、活跃会话恢复与消息顺序管理，支撑前端连续对话体验。
上下文管理机制: 围绕 Session State、最近消息、历史摘要、长期记忆与知识片段构建统一上下文输入，支持 current_mode、current_step、current_intent 等状态字段管理。
摘要与长期记忆: 实现长对话滚动摘要机制，对历史消息进行压缩保留最近消息窗口；同时支持从对话中提取偏好、目标、约束等长期记忆候选，增强后续回答的连续性。
RAG 知识增强: 实现知识文档上传、文档分片与检索增强问答；在 Agent 服务中接入 DashScope Embedding 与 Redis 向量存储，支持知识片段召回并注入回答生成链路。
三服务架构协同: 采用 React 前端 + Spring Boot 业务后端 + FastAPI Agent 服务的解耦设计，Java 端负责鉴权、会话与业务逻辑，Python 端负责 Agent 推理与工具调用。
前端 AI 交互体验: 基于 React + TypeScript 实现会话恢复、打字机输出、普通/策略模式切换、策略报告展示、记忆与知识侧边栏等交互能力，提升 AI 对话的可用性与可解释性。
前端工程化与状态管理: 使用 TanStack Query 管理动态、活动等页面的服务端状态与缓存，结合 QueryClient、useQuery、useMutation 实现查询缓存、乐观更新与前端数据流管理。
实时行情与可视化: 接入 WebSocket 实时价格推送与 REST 历史数据查询，结合 Recharts 展示价格走势和技术指标，为 AI 策略分析提供数据支撑。
用户体系与社区能力: 完成登录注册、短信验证码登录、JWT 鉴权、头像上传、动态发布与点赞等功能，并结合 Redis 缓存和 RabbitMQ 异步通知支撑完整产品链路。
项目成果: 独立完成产品设计、前后端开发与 Agent 服务联调；将 AI 能力从单轮问答扩展为具备会话状态、历史摘要、长期记忆和知识检索接入的上下文系统，形成可持续迭代的 AI 交易辅助产品基础架构。
